# Footer Component Documentation

The `Footer` component (`src/components/layout/Footer.tsx`) is the primary global layout footer, displaying brand meta-content, contact info, and legal links.

## 1. Component Overview
- **Path:** [Footer.tsx](file:///c:/Antigravity/Mith%20%20studio/artifacts/mithraa-studio/src/components/layout/Footer.tsx)
- **Role:** Closes pages with consistent context links (Home, Services, Portfolio, Terms, Privacy) and contact coordinates.

## 2. Technical Implementation
- **Dynamic Year:** Extracts current system year using `new Date().getFullYear()` to prevent hardcoding.
- **Icon Set:** Integrates Lucide-React SVG nodes (`Mail`, `Phone`, `Instagram`, `ArrowRight`).
